# EmoVoice Assistant 🎤🤖

A smart voice assistant that reacts to your emotions and voice commands.

## Features
- Wake word activation (“Hey Emo”)
- Sentiment-aware reactions (happy, sad, angry)
- YouTube playback by voice
- Dictation to file
- Calendar reminders
- GUI with Tkinter

## Folder Structure
```
emovoice-assistant/
├── assets/
│   ├── calm.mp3
│   └── quotes/
├── data/
│   ├── mood_history.json
│   └── todo.txt
├── emovoice.py
├── notes.txt
├── requirements.txt
└── README.md
```

## How to Run

```bash
pip install -r requirements.txt
python emovoice.py
```
